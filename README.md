## Resumen
Este proyecto consiste en una aplicación de escritorio básica desarrollada en Java utilizando JavaFX.
El propósito fundamental del ejercicio es mostrar cómo crear y desplegar diálogos emergentes de notificación (Alert)
de tipo informativo para interactuar con el usuario a partir de un evento.
## Características
Ventana Emergente Estándar: Utiliza la clase Alert con el tipo AlertType.INFORMATION para mostrar un cuadro de diálogo con un icono nativo de información.
Interfaz Centralizada: Emplea un contenedor StackPane para posicionar el botón de acción automáticamente en el centro de la pantalla principal.
Flujo Modal (showAndWait): 
Al hacer clic en el botón, la alerta bloquea la interacción con la ventana principal hasta que el usuario cierra el diálogo o presiona el botón "Aceptar".
